About Linux Auto

プロジェクトおよび開発者情報

Linux Auto

Version 1.0.0 (Ubuntu & Kubuntu Edition)

Google DHU（Desktop Head Unit）だけではコマンドラインでの操作や設定が必要で難易度の高かった Ubuntu系列OSへのAndroid Auto接続を、ワンクリック＆GUIでサポートするツールです。

プロジェクト名 Linux Auto
開発者 エノキ電気 ENOKI ELECTRONICS
ホームページ https://enoki.xyz
GitHub https://github.com/jikantoki

主な機能と特徴

  • ワンクリック有線接続: desktop-head-unit --usb をバックグラウンドで安全に起動
  • 切断時10秒自動復帰: USBケーブルが抜けてプロセスが落ちても、10秒間自動的に再接続を試行
  • GUI設定エディタ: ~/.android/headunit.ini（解像度・DPI・タッチ・FPS）を直感的に設定
  • Zero-Dependency 設計: Python 3標準ライブラリ100%で動作し、Ubuntuのバージョンアップ等による依存破壊を排除
